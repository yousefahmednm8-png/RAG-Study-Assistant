# RAG Study Assistant

Local Retrieval-Augmented Generation (RAG) application that answers questions
from your study documents. Upload PDF/TXT files, build a vector index, and ask
questions — the app retrieves the most relevant passages, reranks them, and
answers with cited sources. Runs locally via Streamlit, FAISS, and Ollama, with
an optional Gemini-based generation evaluation harness.

## Features

- Upload **PDF** and **TXT** documents and build a searchable knowledge base
- Dense retrieval (`intfloat/multilingual-e5-base`) followed by
  reranking (`BAAI/bge-reranker-v2-m3`) for high-precision passage ranking
- Lexical **BM25** retrieval for hybrid (dense + BM25 + RRF) experiments
- Answers generated by a local LLM served by **Ollama**
- Every answer cites its sources (document, page, chunk)
- Real-time Streamlit UI to add/rebuild the index and ask questions
- 30-question Gemini generation evaluation with checkpointing and judging

## Architecture

```text
Streamlit app (app.py)
   │
   └─▶ Dense Retriever  (e5-base, top-15)     src/retrieval.py
          │
          ▼
      Reranker          (bge-reranker-v2-m3)    src/reranker.py
          │
          ▼
      Prompt Builder                             src/pipeline.py
          │
          ▼
      Ollama LLM        (chat model)            src/generation.py
          │
          ▼
      Answer + Sources
```

Core abstractions (per `graphify-out/GRAPH_REPORT.md`): `RAGPipeline`,
`build_pipeline()`, `VectorStore`, `EmbeddingModel`, `GeminiGenerator`.

## Tech Stack

- Python 3.10+
- Streamlit (UI)
- sentence-transformers (`intfloat/multilingual-e5-base`, 768-dim embeddings)
- FAISS (vector store, `data/vector_store/`)
- `BAAI/bge-reranker-v2-m3` (reranker)
- rank-bm25 (lexical retrieval)
- Ollama (local LLM server)
- pypdf (PDF text extraction)
- google-genai (evaluation only)

## Installation

Requires Python 3.10+, Git, and Ollama.

```bash
git clone <repository-url>
cd rag-study-assistant

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Ollama Setup

1. Install Ollama from https://ollama.com and start the server
   (`http://localhost:11434`).
2. The app defaults to `gemma4:31b-cloud`. If unavailable, pull another model
   and set it in `src/generation.py`:

   ```bash
   ollama pull qwen3:8b
   ```

## Run the App

```bash
source .venv/bin/activate
streamlit run app.py
```

## Run the Tests

```bash
python -m pytest -q
```

## Generation Evaluation (Gemini)

```bash
# .env
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.5-flash-lite
GEMINI_JUDGE_MODEL=gemini-3.5-flash-lite
```

```bash
uv run python evaluations/evaluate_generation.py
```

Results checkpoint to `evaluations/results/generation_gemini.json`.

## Retrieval Evaluation

```bash
uv run python evaluations/evaluate.py
```

## Vector Index

A prebuilt index is committed under `data/vector_store/`. To rebuild, upload
files in the app and click **Build Knowledge Base**.

## Known Limitations

- Generation requires a running Ollama server.
- Embedding/reranker models download from Hugging Face on first run.
- The prebuilt index covers only the bundled study-guide PDF.
